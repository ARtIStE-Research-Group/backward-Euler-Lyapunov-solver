# Changelog

## 1.0.0 - 2026-09-19

- Initial variable-step backward-Euler integrator for non-stationary differential Lyapunov equations.
- Step-doubling error estimation with P and PI controllers.
- Componentwise scaled covariance error norm.
- Complex-Schur Bartels-Stewart solver without mandatory toolboxes.
- Reuse of full-step and half-step Schur factors for constant state matrices.
- Optional symmetry, PSD and residual checks.
- Three examples, four regression tests, and an English theory/user manual.
